# Today: daily habits

A one-screen daily habit and to-do tracker. It installs on Android as an app from Chrome and works offline.

- Tap a task to tick it. Hold a task to edit it. Swipe a task left to delete it.
- The list resets every day at 4 AM.
- Data stays on the phone. Use **🎨 > Save backup** now and then.

## Update the app

1. Edit the files.
2. In `sw.js`, change `CACHE = 'daily-habits-v1'` to the next number, for example `v2`.
3. Upload the changed files to GitHub. Phones pick up the new version the second time you open the app.
